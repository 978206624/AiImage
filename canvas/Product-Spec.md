# Product Spec

## 内容运营数据

项目后台维护画廊、分类、模板与风格预设等内容数据，用于前台画廊页、模板库与生成页的快速套用。

### 当前要求

- 画廊图片必须使用真实生成的位图图片，不使用 SVG 或 data URL 占位图。
- 画廊图片上传到项目配置的 OSS，并将 OSS 公网 URL 写入 `gallery_images.image_url`。
- 模板封面图片上传到项目配置的 OSS，并将 OSS 公网 URL 写入 `prompt_templates.cover_image_url`。
- 新增内容应优先覆盖常见高价值生图场景，包括人像、商品、空间、游戏概念、国风插画、社交媒体、时尚、美食、交通、教育科普等方向。
- 提示词可参考 GitHub 上开源的提示词数据集与模板写法，但不得直接复制第三方示例图片。
- 数据写入应保持最小必要变更，不修改无关业务代码。
